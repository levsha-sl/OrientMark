# event_organizer

Этот клиент будет создан для организаторов спортивных мероприятий.

## Разработка

Проект рассчитан на Flutter 3.47.x и Dart 3.13.x. Статический анализ и сборка
debug APK проверены на Flutter 3.47.2 / Dart 3.13.2.

Android-сборка использует Gradle 9.3.1, Android Gradle Plugin 9.1.0 и Kotlin
2.4.0. Целевая версия байткода Java/Kotlin — 17; минимальная версия Android
при использовании Flutter 3.47.2 — Android 7.0 (API 24).

Из каталога `event_organizer`:

```sh
flutter pub get
flutter analyze
flutter build apk --debug
flutter run
```

Файл `pubspec.lock` следует хранить в Git для воспроизводимого выбора версий
зависимостей. Для проверки доступных обновлений: `flutter pub outdated`.
